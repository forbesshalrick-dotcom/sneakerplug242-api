Why it works this way

The labels are the whole trick.

It asks the size first

Sending twelve photos before knowing the size burns the customer's data and their patience. One question, then a short answer — that is the difference between a helpful bot and a spammy one.

It reads bad spelling

"Blackwork shoes" is not a category in any database. The bot turns it into black + work shoe before it searches, the same way a person would.

One photo, one label

Every option gets a code underneath it. The customer types two characters instead of describing "the one with the strap" — and the bot knows exactly which pair that is, with no back and forth.

It only shows what exists

The album is built from the live count in that size. Nothing gets offered that has to be walked back five minutes later.

Delivery still gets a human

Once an address is in, staff get an alert on their own phones. The bot arranges the run; a person still drives it.

Then the shelf comes down

The sale writes back to inventory, the count drops, the order gets a number, and the whole chain is logged so any sale can be audited later.
